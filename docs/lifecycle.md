# 时间、请求与权限生命周期合同

本合同把真实项目反例转成期序的实施约束。来源为作者的「攻击藏书素简记」工程讨论（`01a0b55c-d28f-7363-ad29-479c66f6e79b`）以及本项目首次执行失败。参考工程的修复不构成期序已经通过的证据；下列每项仍需在对应阶段真实验证。

## 时间与期限

- 后端注入 `Clock`，数据库保存 UTC，API 使用带偏移的 ISO 8601；界面明确按 Asia/Shanghai 展示。不能用浏览器时钟裁决资格、释放或审批。
- 所有时段为半开区间 `[start,end)`。相邻时段不冲突；楼层、区域、座位的包含关系参与冲突计算。
- 操作取得协调锁后重新读取当前时间、规则版本、身份、状态与期限。排队前检查通过不是提交资格。
- 预约宽限期、候补确认期等在业务建立时保存实际截止时间；后续配置变化只影响新业务。页面倒计时是提示，不改变权利。
- 定时任务发现的行是候选。任务在事务内锁定并复核当前状态、版本和截止时间后才能改变事实；恢复后的行不能被旧扫描释放。

## 使用权与状态

长期席位的使用权不依赖当前是否有人坐着。短期预约确认、正常结束、主动退出、治理处置分别有原因和事件。外部占用申请、学生报告、通知成功不能直接改变已生效权利。

批次冻结后不能重新挑随机来源；执行租约、任务身份或上一次成功只能说明谁曾尝试。最终写入仍须检查本次 owner/attempt、业务版本与当前状态。外部网络访问在事务外执行，写入前重新验证业务坐标。

## 请求、重试与未知结果

有副作用的业务使用 actor + operation + idempotency key + canonical body hash 绑定请求。相同键不同内容拒绝；重放只能取得同一 actor 的已提交收据。结果收据和业务副作用同事务提交。

超时、断网或响应丢失属于 `UNKNOWN`，不能直接呈现“操作失败”或生成新键再提交。客户端保留原键和原内容，查询/重放确认最终事实。有限重试、退避和明确重新登录路径必须存在；后台读成功只能清理属于该读取的错误，不能清除未知写结果或事务回滚提示。

通知通过事务 outbox 保存，再由有界任务投递。任务失败不回滚已取得的权利；重投以事件身份去重。不能把“已写入 outbox”显示成“用户已收到”。缓存不是裁决源，旧加载不得覆盖新的版本或跨用户数据。

## 身份生命周期

第一版是有明确期限的 opaque session，过期重新登录，不暗中引入 refresh-token 协议。外部绑定仅提供身份事实，不自动授予老师、管理员或楼层范围。

前端每次登录、退出和身份变更提高本地 generation。请求捕获 actor/generation；旧 A 的响应不能投影到新 B 的界面，旧 401 不能清除 B 会话，写请求不能因恢复登录而换 actor 重放。Cookie 控制请求需串行处理，不能仅靠忽略旧 JS 回调来防止旧 Set-Cookie。

后端读入口检查会话当前有效性；业务写还必须在协调锁后、提交前复核 active、auth version、session 及 scope。管理员撤权和业务写要通过共同身份协调边界建立先后顺序。M1 的入口检查不宣称已证明后续写事务的提交保护。

## 启动、停止与页面

API 仅在应用 `ACCEPTING_TRAFFIC` 后服务业务；初始化中或 drain 时返回结构化 503 `APPLICATION_NOT_READY`。数据库连接成功不等于初始化已完成。关闭时保留未知请求收据，清理仅操作经过 PID、创建时间、路径和命令行核实的本工程进程。

管理端桌面和手机共享业务语义。进入详情和审批后返回应保留 tab、筛选、搜索、日期、滚动与草稿；直接链接有可理解的父页面。学生输入时要保留相邻字段与操作上下文，键盘行为未经微信真机观察不得声称通过。

401 提供重新登录且防止旧请求误退出；403 说明范围限制；404 给出返回入口；409 解释冲突并读回当前事实；422 保留输入并定位问题；503 可恢复且不显示空数据冒充正常。加载、错误、空结果和陈旧数据必须可区分。

## 阶段验证义务

| 边界 | 阶段 | 必需反例 |
| --- | --- | --- |
| readiness | M1 | 初始化/drain 的真实 HTTP 503，恢复后登录 200，早期无 session 写入 |
| 时间与锁 | M2 | 取得锁前后跨越期限；边界相邻；旧到期扫描与到场确认竞争 |
| 会话提交资格 | M2/M6 | 撤权、退出与排队业务写竞争，旧 actor 不得获得新权限 |
| 未知提交 | M2/M6 | 丢响应后同键恢复；并发同键；异体同键；旁人无法读收据 |
| 分配执行身份 | M3 | 过期执行者回写；固定输入恢复；官方结果唯一；未来来源验证失败停止 |
| outbox/报告 | M4 | 重试不重复事件，报告未核实不成为公开事实，旧任务不能覆盖恢复状态 |
| 前端所有权 | M5/M6 | A→B 后旧成功/401；读成功不清未知写；返回保留筛选日期草稿 |

生产吞吐、多节点、未接入校园身份、真实维修效果与所有手机平台行为不是上述测试的默认推论。
