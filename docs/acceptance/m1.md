## 声明边界

支持：真实 MySQL 8 迁移与 READ COMMITTED；会话摘要存储、cookie CSRF、过期/active/authVersion 当前检查、错误封装、角色/楼层读取隔离、外部 provider/subject 命名隔离、空间查询和数据库结构约束、演示禁入生产、就绪拒绝。

不支持：后续业务写的提交权限、并发预约、长期分配、活动发布、维修治理、前端/微信真机、暗室真实接入、生产容量或全项目 Release。测试数量和绿色 CI 不能把这些范围升级。

新的 readiness PR 和 exact-main fresh 门禁仍需完成。执行坐标会进入后续施工记录，不无限重写历史报告产生自指。
