# 页面素材与来源

两端六份位图为本项目生成的演示素材，不是真实图书馆照片或建筑测量；学生详情明确标注“演示示意图片”。处理后的文件名、尺寸、字节数及SHA-256在[素材清单](assets.json)，每端合计775731字节。学生与管理端使用相同字节，页面不加载第三方图片URL。来源参考图只用于视觉方向，不作为已实现页面截图。

生成素材随本项目MIT许可交付；不声称生成内容具有任何第三方实景真实性。`prepare-assets.py`仅缩放/压缩已生成原件，不能从缺失原件伪造原摘要。运行项目使用仓库中的处理成品，不需要重新生成。

图标采用Phosphor Icons，固定`@phosphor-icons/core`2.1.1和`@phosphor-icons/vue`2.2.1，遵循MIT许可。导出的学生SVG保留[原许可](../student/src/static/icons/LICENSE.txt)，SVG仅用于功能图标。地图由公开演示数据坐标绘制，不冒充真实校园平面图。

M5检查素材是否实际加载、无私有原图泄露与结构可用；最终图像保真、排版、色彩和同状态参考图比较留M10，不能把生成素材或构建成功称为最终视觉验收。
