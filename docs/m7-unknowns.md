# M7 · 尚未证明与重入坐标

这是未知账册，不是缺陷已修列表。以下统一归属**期序维护者**；独立角色、实际事故、新依赖版本或对应部署能力出现时，重开对应最小机制。任何已观察到的核心失败仍须修复和原条件复验，不能迁入此表逃避处置。

当前单实例限定：Java17/MySQL8.0.44，主库事务、独立本机账册、隔离API/H5。真实数据库故障与H5观察只支持各自合同。每次重入需先冻结新的exact clean SHA/Plan/环境/调度，不覆盖原Bundle。

## U01 · 微信设备与原生键盘（F14/F15，NOT_PROVEN）

- 触发：iOS/Android微信渲染、键盘、安全区、系统返回或小程序后台恢复。
- 不变量/影响：操作入口可达、上下文保留、UNKNOWN与当前主体不漂移；可能遮挡确认与错误恢复。
- 证据缺口：当前为真实H5和微信构建，未观察实际微信设备。
- 环境：合法AppID、开发/体验权限、可用HTTPSAPI及两种用户设备；H5窗口缩放不能替代。
- 重入：M10精修合同与M7浏览器合同的消息末页、UNKNOWN重载、换号、地图返回trace；开发工具编译后逐设备记录前后台/键盘/安全区。
- 重开：设备、平台版本或体验权限就绪后由维护者执行；仅UI素材可后置，设备发现的使用权/隐私错误立即阻断。

## U02 · 浏览器真实存储拒绝与晚Cookie（F08/F09，NOT_PROVEN_REAL_POLICY）

- 触发：隐私模式/配额/浏览器策略拒绝，或注销/换号之后旧响应才写Set-Cookie。
- 不变量/影响：原键不能丢；旧主体不能获得新读写权；模型通过不证明真实浏览器凭据副作用。
- 证据缺口：45例Transport/Storage模型和正常浏览器换号成立，尚无真实策略/晚Cookie受控调度。
- 环境：能明确配置并记录存储策略的浏览器、同origin两文档、owned代理针对原响应延迟；只用本项目demo身份。
- 重入：执行入口ACTOR-KEY/STORAGE-DENIED及browser原14trace，加入新sealed观察：A在途→B登录→放行A响应→查session/私有页面/UNKNOWN；拒绝扫描/写入/删除后核对原键与网络传输。
- 重开：取得该策略夹具或发现实际异常；当前不声称所有浏览器策略已经安全。

## U03 · 多节点/主从故障/长网络分区（F05/F12/F15，UNSUPPORTED_DEPLOYMENT）

- 触发：同时运行两API写节点、MySQL主从切换、长期网络分区或从库旧读。
- 不变量/影响：单一使用权、完整结果、read-your-writes与独立账册所有权；错误部署可能重复授予或无法恢复。
- 证据缺口：当前独占本机journal明确为单实例，不能迁移成共享仲裁或分布式exactly-once声明。
- 环境：至少两独占API节点、可控MySQL故障拓扑、共享裁决设计与独立外部oracle；不是开启第二PID即获得支持。
- 重入：先版本化架构/恢复合同，再重跑COMMIT原29、恢复原22，加入分区/切主/迟到旧节点×双批次/审批trace，查询两节点及原始SQL权区间。
- 重开：计划支持对应部署、事故涉及该环境或独立角色要求扩展产品声明；未完成前部署说明只允许单实例主库。

## U04 · 全主机回滚、真掉电与磁盘语义（F12，NOT_PROVEN）

- 触发：数据库与本机独立journal同时恢复旧快照，真实电源丢失、文件系统/磁盘未持久化。
- 不变量/影响：已经向外交付的事实不能因整个机器回滚被静默重发/重分。
- 证据缺口：旧DB保留独立账册、缺账册拒绝、COMMIT歧义恢复已实测；不证明独立存储本身跟主机一起回滚或硬件fsync保证。
- 环境：独立虚拟机/存储快照和机器外不可回滚交付账册；不得对用户宿主或共享MySQL掉电。
- 重入：m7-restore合同T0/T1/缺账册原trace与commit-reply原trace；在新机器保存外部交付原文后回滚全机，验证就绪/写入/任务不得凭旧世界取得资格。
- 重开：出现专属VM/真实灾备目标或计划支持全机回滚；当前恢复承诺不超过独立账册仍存在的边界。

## U05 · 生产容量、利用质量与长期公平（F01/F15，NOT_PROVEN_CAPACITY）

- 触发：大批次/大量并发/长期候补、极端偏好分布、缓存或生产资源限制。
- 不变量/影响：容量缺口不能被人工稀缺伪装；期限内完整发布，资源不能超卖；最大人数不等于所有偏好福利最优。
- 证据缺口：65,536小图和2,048完整rank样本独立枚举、实际事务组合成立；没有生产SLO/100申请110实际SQL席位规模验收或长期公平统计。
- 环境：独占容量实验实例、预先公布资源/时间/并发预算、独立最大匹配oracle；不是共享宿主压测。
- 重入：F01 Q/N反例扩展100/110与安静30、实际完整批次SQL/逐人通知集合；记录计算/发布/递补时限、队列与最大匹配，超预算如实拒绝或延迟。
- 重开：真实规模或SLO确定后维护者先封合同再执行；当前不公布未经实测的吞吐与百分位。

## U06 · 外部身份长期故障与校园SSO（F13，NOT_PROVEN_PROVIDER）

- 触发：第三方长时间不可用、真实校园SSO票据/撤权传播、新issuer格式。
- 不变量/影响：身份连接不能自动取得期序审批权限；过期证明不能授予新写入，已提交回执仍可追踪。
- 证据缺口：真实暗室当前身份和受控租约/命名空间/撤绑组合成立；不是校园SSO或所有提供方故障策略。
- 环境：经授权的提供方测试环境、固定issuer合同与撤权/租约预算；不扫描外部真实账号。
- 重入：external-identity-and-recovery合同、ExternalIdentityIT的proof过期锁等待/绑定撤销/已提交回执trace，另封该提供方真实断联及恢复观察。
- 重开：新增提供方、声明降级可写或现实长故障；维护者核对写与只读的不同资格。

## U07 · 时间跳变与原子发布的物理停止（F02/F04，NOT_PROVEN_PHYSICAL_SCHEDULE）

- 触发：宿主时钟向后/前跳变；大批候选持久后进程在发布中途被物理停止。
- 不变量/影响：截止及确认不得无限漂移；外界不能出现半个正式世界、任务不得选择新随机源。
- 证据缺口：受控Clock、锁等待×截止、实际事务异常回滚与COMMIT丢回应/重启成立；不是全部NTP策略和发布每个物理指令点的kill调度。
- 环境：owned进程/独占库、可控Clock适配器与指定发布SQL帧阻断、独立SQL观察者；不得修改宿主系统时间。
- 重入：时间/分配合同与PreparationIT publicationFault/publicationCrossingDeadline，新增sealed夹具：候选落盘→暂停第二正式写→停owned PID→同快照重启→正式全集/通知/权区间比对；时钟跳变先确定合同禁止/允许结果。
- 重开：运行时钟策略变更、发现新提交机制或独立审阅要求该物理调度；不能声称验证所有崩溃点。

## U08 · 现实设施、维修、活动与通知可达（F10/F11，REALITY_OUTSIDE_SOFTWARE）

- 触发：实际插座故障、施工噪声、线下活动变更、用户未阅读或微信推送渠道失败。
- 不变量/影响：报告不等于事实、安排维修不等于解决、已投递不等于已读；不能用演示图片与SQL替代现场事实。
- 证据缺口：报告核实/维修复验/来源独立、持久通知及去重成立；没有真实馆内测量、维修人员执行、微信送达/用户理解证据。
- 环境：授权场馆资料/维修流程与微信订阅消息测试渠道，真实用户可用性观察需去标识化。
- 重入：venue/conflicts合同的报告→核实→工作完成→复验、活动换地/取消逐人结果，记录软件事实和外部现场证据各自坐标；M10替换演示素材前核对来源许可。
- 重开：接入真实校园试运行或通知渠道；现阶段公开明确演示，不把软件完成升级为现实处置完成。
