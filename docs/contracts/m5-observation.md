# M5 观察合同 0.1

本合同先于M5正式采集执行冻结。阶段资格必须分开核对API/MySQL、固定依赖构建、实际安装页面和公开候选；原施工截图/ZIP不能升级为固定候选资格。M5仅保证主流程可用、素材可加载和合理结构，最终视觉按M10。

## 原生与构建证据

`qixu-native/0.11`、M5 Plan1保留M4全部必需案例/测量，增加明确列名的Cookie读所有者、范围白名单、本人历史分页、维修空引用动作、原子停止及竞争。Maven须clean verify且真实隔离MySQL；原生记录HTTP、SQL与fresh XML；缺失、跳过、重复案例不能填通过。JAR必须本次产生并绑定源码摘要，禁止从旧target继承。

前端采集器0.1在干净exact commit上先seal，再git archive到新目录；npm ci、共享内核编译/31条显式机制案例、两端类型检查和H5/微信/admin构建分别记录退出状态。测试XML必须本次创建且每个指定案例仅出现一次，依赖和产物记录摘要/文件数，三份产物非空。微信构建不证明认证、上传、HTTPS服务、iOS/Android键盘或真实设备。

## 安装页面

新页面验收只用上述producer绑定的JAR和前端产物，正常Clock、专属端口与本项目数据。浏览器保存源码/producer摘要、视口、具体动作、实际DOM/截图和业务回执；写后由真实MySQL与授权详情核对终态，不把Toast或单次4xx当权利事实。

必需主链：学生找空间/筛选/档案/收藏对比/短约读回取消；长期申请/结果/候补的可解释状态及期限；老师场地申请→范围管理员批准→老师活动发布→学生参加/退出；学生反馈/私有图片→核实→维修安排→工作完成仍待复验→缺恢复事实拒绝→明确复验关闭；站内通知与本人上下文。桌面与390px管理入口、不同范围管理员及真实跨文档会话控制分别核对。受控故障/Clock用原生证据，正常安装页面不能冒充时间已跨日或物理维修。

发生遮挡、无恢复、丢输入、旧主体泄漏、未知被抹除、字段/状态虚构，停止M5资格并保留首次输出；修复从新候选重取受影响证据，未受影响证据只在明确相同producer坐标内使用。原子停止、回执404和正常拒绝与产品失败分别分类。

## 资格与边界

Core消费采集器的真实事实作四态裁决，不取得宿主MySQL/浏览器/微信管理权。构建PASS、原生PASS、页面操作成立、公开CI及exact-main有效是不同事实；M5说明列出各自坐标。验收不宣称生产容量、备份恢复、外部身份、真实校园空间/维修、原生真机或最终视觉。M6故障/集成、M7错题、M8两名独立角色和M10都不被替代。
