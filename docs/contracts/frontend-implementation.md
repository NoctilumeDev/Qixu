# M5 · 两端实施合同 0.1

先于前端代码冻结。继承M0、视觉、生命周期和网络合同，不把生成海报当产品运行截图。学生使用uni-app Vue3/TypeScript，构建微信小程序与H5；管理端独立Vue3/TypeScript/Vite。共享DTO、状态文字、时间转换及请求恢复内核，通过不同传输适配器消费真实API，不复制后端裁决逻辑。

## 页面与保护行为

学生首页、空间地图/可访问列表/档案、透明筛选、收藏最多6项与对比；短约时段/到场/取消/结束；长期批次规则/志愿/必需设施/预授权兜底与更高志愿候补/回执/解释/确认/退出；教室场地申请；活动详情/预约/候补/取消；本人反馈/受权图片/补充重开；本人陈述申诉；站内通知与未读；登录和我的。期限/可用性来自服务器，不显示模拟实时有人状态，不强制长期每日签到。

管理端地图、列表与详情、本人组织活动和场地申请、范围内审批、批次配置与固定未来来源、冻结/确定性计算/取消条件、影响preview及完整处置、反馈核实、维修工作与明确复验、治理与独立复核、站内消息及运行/审计投影。老师只有组织入口，空间范围管理员才有审批入口；前端隐藏不是权限证据。地图、待办、详情桌面并列，手机依次进入；批量配置提示桌面，不隐藏现场审批与恢复入口。

空间地图是数据库坐标图，不冒充真实建筑图。已采集unknown分别展示；生成照片明确演示示意。事件公开依合法场地事实，换地保留参与并刷新通知；长期未知/落选明确下一步，不显示无限申请中。

## 请求所有权与恢复

- 登录/登出/会话变更串行，generation变更清空当前主体数据；GET捕获generation及加载序号，旧响应不覆盖新主体/新筛选，旧401不退出新会话。
- student Bearer与admin HttpOnly cookie+CSRF分别传输。小程序token不放URL或日志；H5和admin开发代理同源，不用通配凭据。
- 有副作用请求发送前保存actor、path、不可修改原DTO、幂等key及状态。超时、断网、5xx、无法解析成功视为UNKNOWN；界面持续显示恢复入口，GET成功不能清除它。receipt404不解释成未发生；有限同键重放或查询，不能换正文/换actor恢复。不同意图先处置原未知动作。
- 请求键、会话及草稿按主体隔离；未确认记录重载仍可恢复。未知记录有最大数量和可见清理条件；不能以清理本地记录撤销服务器使用权。敏感反馈/依据只在内存，离开/退出清除，不塞通用持久草稿。
- 401重新登录并保留同主体恢复路径；403范围说明；404父入口；409保留输入、明确版本/空间冲突并读回；422定位字段；503重试且不把旧数据标成新数据。普通读错误、未知写、确定拒绝分区显示。
- 每个业务写最终从返回回执+详情读回成立；成功回执是历史事实，不能覆盖详情当前状态。

## 上下文、时间和输入

路由保存筛选/搜索/日期/选中层及滚动；详情返回保留原上下文，直链有父入口。前端按Asia/Shanghai显示，业务输入转含offset且秒精度；服务器Clock裁决。日期跨UTC不改变用户选的本地日；无效输入不发请求。

学生小程序使用原生表单/textarea/picker，安全区、键盘高度响应与连续字段滚动；管理端手机单列表与底部操作区域不遮字段。动画有限、尊重减少动态，不同时启用系统顶起和重复自定义位移。微信编译不证明iOS/Android实际键盘；没有真机证据必须保留待验。

## 必需的限定管理读取增量

现API没有限制列表、待投递概况和审计读取。只增加范围内分页GET `/admin/space-blocks`、GET `/admin/operations`及GET `/admin/audit`：限制按当前admin_scope过滤；投递概况仅该范围可归属的事件统计/最旧等待时间，不返回消息全文、票据、密码或全校数字；审计只投影能归属该范围的已知实体及当前管理员本人动作。未知实体不得退化为全校通配。分页≤50、字段白名单、老师/学生403。历史限制详情保持现权限。无后台任意SQL、修改身份/范围、改正式结果或自动授权接口。

## 验收与停止

锁定工具/依赖，H5、微信产物、admin构建与类型检查；请求内核反例（A→B旧成功/401、乱序GET、receipt404、丢响应、重载恢复、旧CSRF/Set-Cookie）使用独立可控传输，不能只镜像实现。真实浏览器+真实HTTP/MySQL主流程按学生/老师/两个不同范围管理员执行，保存固定SHA/构建字节/视口/截图/步骤/最终数据库事实。

设计QA比较用户原图中应用内容，记录规范化后的手机/桌面/390px管理端、字段层级/按钮安全区/真实状态和五项视觉表面；修复P0/P1/P2。正常/空/错误/未知/加载均需可理解。没有后端端点或当前权限时不能提供假成功按钮。遇到越权、未知被猜失败、重复事实、上下文/键盘按钮遮挡、旧主体泄漏或没有browser截图，停止资格声明并保留首次证据。

VeriTrail以封存M5计划消费明确构建/浏览器/数据库事实。当前Core不原生管理微信设备；实际图书馆、生产容量、微信认证、校园身份、原生真机键盘不从H5测试继承资格。M7扩展全操作序列和故障组合，M8两名独立审阅者仍必需。
