# 候补、退出与周期关闭合同

状态：M0 业务基线。

## 固定顺序

初次分配生成稳定候补顺序。空位出现时，依次检查仍有效且接受该座位的人；没有重叠长期权者可正常补位，已取得本批次兜底且预授权保留较高志愿候补者仅能通过原子升级补位。拥有其他不兼容重叠权者不能再取得一席。不适配者跳过本次空位，但不失去原候补顺序。不能要求接受明确不符合条件的座位。

候补补位先生成限期要约，再由本人确认；等待确认期间该座位不能同时发给别人。超时/拒绝记录原因后按原顺序继续，重试任务不重复要约。

兜底升级要约等待确认时保留原位；确认事务将旧权结束和新权生效一并提交。超时、拒绝、冲突或任务失败均不丢原位。每次递补及失败/期限变更有本人持久通知和可查询解释；收件项由原事件键去重。

若有多个空位，同轮扫描资源的次序须固定并留记录，不能让后台工作线程时序改变结果。是否允许拒绝后继续等待其他兼容席位，在批次规则中明示；第一版保守方向为允许并跳过本人刚拒绝的同一空位，避免无限反复通知。

## 合法退出

主动退出、周期结束、资格被纠正为无效、明确违规且完成处置程序可以结束长期权。没有签到/学习时长自动收回规则。“暂未联系上”本身不证明弃用。

每次变更保留来源、操作者、时间、理由和关联原分配。收回有通知、合理期限和申诉记录；申诉不默默改写既有分配，纠正需要明确恢复或替代方案。

## 周期关闭与失效

所有期限按服务端时钟和统一时区解释。到期权在查询和写入校验中立即失效，不依赖定时任务刚好运行。清理任务只补齐可重复的状态与通知。

批次关闭停止发放新要约，未确认要约失效，已结束长期权不能被补位任务重新激活。备考区恢复常态使用模式时保留历史记录，不删除分配证据。

## 关键验收

- 退出、要约确认、超时释放并发，至多产生一个有效拥有者。
- 不兼容者保留顺序；过期/违规/退出者不会越过资格规则被补位。
- 任务重启、延迟和重复执行不改变初始随机顺序、不重复通知或分配。
- 一个用户两批次并发确认仍只能持有一个重叠长期权。
- 关闭后回放旧请求不能复活使用权；取消后历史解释仍可读。
